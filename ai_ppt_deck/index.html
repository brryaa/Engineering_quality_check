全局因果排查能力
  • 跨网络、DB、K8s 集群与应用层的级联故障排查极其复杂。

MODULE 02 / CONTEXT ENG

上下文工程 (Context Engineering)

从 Prompt 调优到上下文图谱的终极进化

05 / 20
💡 讲师提示：在生产级系统中，真正的技术壁垒是 Context Engineering —— 如何将数 GB 代码库与架构拓扑精准打包喂给 LLM。
Prompt Eng vs Context Eng
对比维度Prompt EngineeringContext Engineering
适用场景单次交互 / 提问小技巧企业级代码库与运维图谱打包
数据来源人工输入提示词文本AST 抽象树 + Git Commit + 拓扑日志
系统复杂度低（纯文本）高（自动抽取、压缩与切片）
长上下文 (Long Context) 大海捞针优化
  • Needle In A Haystack 模型对超长上下文中间部分的注意力天然衰减。
  • AST 代码解析 基于语法树自动过滤冗余实现，只提取类定义与方法签名。
  • 动态窗口切片 根据依赖图谱动态加载关联模块，保留最强上下文密度。
MODULE 02 / GraphRAG

企业级知识引擎 RAG 演进

从朴素 Vector DB 检索到 GraphRAG & 混合语义召回

06 / 20
V1
朴素 RAG (Naive RAG)
  • 简单的文本 Chunk 切片 + 向量数据库余弦相似度检索。
  • 痛点：丢掉上下文语义，代码类继承链与 API 调用关系彻底断裂，准确率仅 ~30%。
V2
混合检索 (Hybrid Search)
  • Dense (向量相似) + Sparse (BM25 关键词) 结合。
  • 加入元数据过滤 (Metadata Filtering) 与 Rerank 重排序模型。准确率提升至 ~65%。
V3
GraphRAG 代码图谱增强
  • 抽取代码调用链、类关系与微服务依赖生成知识图谱 (Knowledge Graph)。
  • 结合图节点与子图展开，为 LLM 提供完整的全局架构视角。准确率 >90%。

MODULE 03 / DATAOPS

数据库与数据工程 (DataOps)

Text-to-SQL 落地困境突破与 SQL 自动调优 Agent

14 / 20
⚠️ Text-to-SQL 落地三大陷阱与解法
  • 陷阱：字段幻觉、多表 Join 关联错误、慢查询拖垮线上 DB。
  • 解法 (Schema Linking)：仅向大模型注入向量化 Schema 与索引，生成只读受限 SQL。
🤖 DBA 自动调优 Agent
  • 自动抓取 Slow Log，分析 EXPLAIN 执行计划。
  • 给出针对性的索引创建建议（Missing Index Advisor）与重写复杂 SQL，大幅降低 CPU 开销。
MODULE 04 / PITFALLS

生产级 AI 落地四大死亡陷阱

幻觉踩坑、上下文丢失、权限过载与数据污染

15 / 20
01
幻觉误执行
症状：Agent 凭空伪造命令行参数。
解法：Strict JSON Schema 校验与命令白名单沙箱。
02
上下文断崖
症状：长对话中丢失关键架构约束。
解法：GraphRAG 与精细切片，避免纯 Token 堆砌。
03
权限越权过载
症状：Agent 获取 Root 导致误删库。
解法：RBAC 最小权限原则 + 人工二次批准。
04
Garbage In/Out
症状：基于陈旧过时文档引发错误。
解法：建立动态企业知识库更新机制与数据清洗。

MODULE 04 / TRUST & GOVERNANCE

人在回路 (Human-in-the-Loop)

建立可信 AI 的权责划分与控制网格 (Control Mesh)

17 / 20
💡 讲师提示：不要盲目追求 100% 无人驾驶。最好的 AI 架构是“AI 智能建议，资深专家一键批准”。
IT 领域 AI 自治分级 (L1 ~ L4)
  • L1 辅助级 仅提供只读建议与分析。
  • L2 半自治 自动生成 Patch/YAML，需人类 Click-to-Approve 执行。
  • L3 条件自治 预发/测试环境自动闭环自愈。
  • L4 完全自治 高度信任的生产环境自治（极少场景）。
🛡️ 控制网格 (Control Mesh) 设计
  • 全量操作审计日志：记录 Agent 的每一次推理决策与 Tool Call 调用。
  • 一键熔断器 (Circuit Breaker)：紧急状态下一键剥夺 Agent 系统变更权限。
