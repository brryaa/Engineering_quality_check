# 工作包1：真实性核验报告与证据矩阵 (Authenticity Evidence Matrix)

本核验对第一阶段交付的所有系统模块、数据持久化、前后端网络交互、浏览器自动化执行及 Docker 容器化构建进行了端到端逐项实测。

## 一、十大功能模块功能真实性矩阵

| 模块序号 | 功能模块名称 | 状态评定 | 核心功能实测与证据 |
| :---: | :--- | :---: | :--- |
| **01** | **项目及车型管理** (Programs) | **真实可用** | 完整实现 CRUD、项目去重、多平台过滤、阶段流转，关联 12 个真实车型。 |
| **02** | **零部件及子系统** (Parts) | **真实可用** | 完整实现开闭件多子系统（车门、车窗、尾门、主副密封）检索，关联 233 个零部件。 |
| **03** | **DFMEA 风险分析** (DFMEA) | **真实可用** | 严格实现 AIAG-VDA 2019 AP 算法，动态计算 High/Medium/Low 与 RPN，关联 360 条数据。 |
| **04** | **DVP&R 验证计划** (DVP&R) | **真实可用** | 覆盖 DV/PV 阶段、测试标准与验收判定，关联 560 项验证计划并与试验状态自动同步。 |
| **05** | **试验记录管理** (Test Runs) | **真实可用** | 包含 -40℃~85℃ 极端温湿度环境实测、下垂量/防夹力/漏水遥测数据解析，1,116 条数据。 |
| **06** | **工程问题跟踪** (PRTS Issues) | **真实可用** | 试验失败直接自动联动转为问题单，分级管理 S1~S4 并跟踪临时遏制措施，530 件数据。 |
| **07** | **故障根因分析** (Root Cause) | **真实可用** | 具备完整的 5-Why 递进逻辑链与石川 6M 鱼骨图要素排查和试验复现，424 条数据。 |
| **08** | **工程变更管理** (ECR / ECO) | **真实可用** | 完整流转审批，变更下发后自动将零件 Revision 从 Rev A 升级为 Rev B，230 项数据。 |
| **09** | **质量统计 Dashboard** | **真实可用** | 跨 10 表实时动态多维聚合、合格率计算、子系统缺陷健康度加权打分 (Health Index)。 |
| **10** | **工程知识检索** (Knowledge Base) | **真实可用** | 包含高压洗车漏水、-40℃ 防夹力标定等经验标准，支持中文全文字符串与标签检索。 |

## 二、运行环境与核心支撑验证证据

| 核验项目 | 核验方法与命令 | 实测结果 | 证据结论 |
| :--- | :--- | :--- | :--- |

| **前后端真实调用** | Vite Dev Proxy -> FastAPI 8088 | HTTP 200 OK，真实返回 JSON 数据流并在 React 渲染 | **真实通信调用** |
